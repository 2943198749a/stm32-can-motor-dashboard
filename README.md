# STM32F407 / F103 CAN 电机测速与仪表盘

## 当前工程

- `f407/`：来自本地 LED1 工程；F407 通过 TIM2 编码器读取计数、计算转速，TIM1 输出 PWM，每 50 ms 发送 CAN 数据。
- `f103/`：来自本地 F103_CAN_HAL 工程；CAN FIFO0 中断接收、快照与超时判断、LVGL 仪表显示。
- `lcd-alternative/`：保留并同步另一套 LCD 工程，作为备选版本，不等同于当前 F103_CAN_HAL 主界面。

打开相应 `MDK-ARM/*.uvprojx`，按实际芯片、晶振、收发器、引脚和显示屏核对配置。各工程保留本身所需 HAL/CMSIS/FreeRTOS/LVGL 依赖。

## 通信与显示

主链路是 F407 发送 → F103 接收。标准 CAN ID 为 `0x201`，四字节载荷为小端绝对转速×10、序号、状态位（bit7 有效，bit0 反转）。F103 在超过 500 ms 无有效数据时显示失联。LVGL 通过 RGB565 局部缓冲和 FSMC 写屏。

当前为 PWM 开环驱动加测速显示，没有据此实现 PID 速度闭环；序号跳变也可能来自本地发送邮箱忙，不能直接等同总线丢帧。
